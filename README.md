# Web-Application-Penetration-Testing-using-Dvwa
## Objectives

The main objective of this project is to identify and understand common web application vulnerabilities using DVWA. The project focuses on performing security testing in a safe and controlled lab environment. It also aims to understand different attack techniques and learn the basic methods to prevent and mitigate these vulnerabilities.

## Introduction

Web Application Penetration Testing is the process of identifying security vulnerabilities in a web application. In this project, DVWA (Damn Vulnerable Web Application) is used as a safe and legal testing environment. The project focuses on finding and understanding common web vulnerabilities such as SQL Injection, Cross-Site Scripting (XSS), Command Injection, File Inclusion, and File Upload vulnerabilities. The main objective is to understand how these attacks work and how web applications can be secured against them.

## Lab Environment

The lab environment for this project consists of Kali Linux as the attacker machine and DVWA (Damn Vulnerable Web Application) as the vulnerable target application. Tools such as Burp Suite, Nmap, and a web browser are used to perform and analyze different web application security tests in a safe and controlled environment.
## Tools Used

* Kali Linux
* DVWA (Damn Vulnerable Web Application)
* Metasploitable 2 / Ubuntu (DVWA hosting environment)
* Web Browser
* Burp Suite
