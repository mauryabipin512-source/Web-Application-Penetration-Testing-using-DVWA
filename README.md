# Web-Application-Penetration-Testing-using-DVWA
## ## Introduction

Web Application Penetration Testing is the process of identifying security vulnerabilities in a web application. In this project, DVWA (Damn Vulnerable Web Application) is used as a safe and legal testing environment. The project focuses on finding and understanding common web vulnerabilities such as SQL Injection, Cross-Site Scripting (XSS), Command Injection, File Inclusion, and File Upload vulnerabilities. The main objective is to understand how these attacks work and how web applications can be secured against them.
